# 京东到家订单原始采集设计

## 目标

第一阶段只完成可靠的本地原始数据采集：定时调用商家网页实际使用的订单列表接口，将每一次成功响应的完整 JSON 原样保存到本机。此阶段不识别订单类型、不提取订单字段、不去重、不判断状态变化、不发送通知，也不接入咚咚 WebSocket。

## 数据源

使用商家订单网页的同源 GET 请求：

`https://order.jddj.com/order/newManager/tabQuery/all`

每轮请求动态生成以下参数，使用 Asia/Shanghai 时区：

- `o2oOrderType=10000`
- `pageNo`：从 1 开始的页码
- `pageSize=50`
- `orderBy`：空字符串
- `desc=true`
- `startTimeQuery`：当天 00:00:00
- `endTimeQuery`：本轮抓取开始时间
- `preStartDeliveryTime`：当天 00:00:00
- `preEndDeliveryTime`：当天 23:59:59
- `stationNo`：空字符串，沿用当前账号可见门店范围

时间参数在每轮重新计算，不复用网页中曾出现过的固定历史时间。若响应表明存在下一页，依次请求并保存每个页面的原始响应。

## 认证与请求

用户通过本机可见浏览器手动登录。程序只在本机私有文件保存浏览器上下文 Cookie，并将其装载到同域 HTTP 会话中调用订单接口。请求带网页常规的 `Accept`、`Referer`、`X-Requested-With` 和 User-Agent 头。

Cookie、完整请求头和订单数据均不得写入应用运行日志、提交到 Git 或展示在管理页面。

## 采集流程

1. 记录本轮开始时间，计算时间窗口并加载本机 Cookie。
2. 请求第 1 页订单列表。
3. 确认 HTTP 响应为可解析的成功 JSON；否则记录失败并结束本轮。
4. 将该页完整 JSON 响应、不经字段筛选或改写地追加到原始采集文件，并附上抓取元数据。
5. 根据响应中的分页信息决定是否请求下一页；每一页重复步骤 3–4。
6. 在全部分页成功后，写入本轮概要运行日志：开始和结束时间、页数、成功响应数和错误（如有）。

任意一页失败时，本轮标记失败。已经成功落盘的页面不删除，因为它们是真实采集到的原始响应；运行日志须标明本轮数据不完整。

## 本地文件

- `data/raw_order_responses.jsonl`：追加式 JSON Lines 原始采集文件；每行是一次成功的接口响应，不对 `response` 内容作任何业务处理。示例：

  ```json
  {
    "captured_at": "2026-07-29T13:44:53+08:00",
    "request": {
      "page_no": 1,
      "page_size": 50,
      "start_time_query": "2026-07-29 00:00:00",
      "end_time_query": "2026-07-29 13:44:53",
      "pre_start_delivery_time": "2026-07-29 00:00:00",
      "pre_end_delivery_time": "2026-07-29 23:59:59",
      "station_no": ""
    },
    "response": {}
  }
  ```

- `data/runs.json`：近期抓取运行的概要日志，记录成功/失败、页数、响应数及错误摘要；不复制原始订单数据。
- `data/cookies.json`：人工登录生成的私有浏览器 Cookie 文件。

所有 `data/` 文件必须被 Git 忽略。原始响应可能包含个人信息，仅保存在用户本机。

## 失败处理

- 网络超时、服务端 5xx 或非成功 HTTP 状态：记录失败；下一轮重新尝试。
- 返回登录页、HTML 或无法解析为 JSON：判定 Cookie 失效，停止本轮并提示重新登录。
- 分页中途失败：保留已成功追加的页面，运行日志标记为不完整。
- 原始采集文件写入失败：立即停止本轮，避免把“已采集”误报为成功。

## 验证标准

1. 已登录会话下的每一页订单接口 JSON 都被完整写入 `raw_order_responses.jsonl`。
2. 连续两轮采集即使返回相同订单，也各自保留原始响应，不做去重或覆盖。
3. 多页结果按页逐条保存，且每条带有实际请求时间窗口和页码。
4. Cookie 失效、非 JSON 响应、网络失败和分页中断都能在 `runs.json` 中看出。
5. 自动化测试使用模拟 HTTP 响应和临时目录，不访问京东真实服务或使用真实 Cookie。
